In the CICIoT2023 traffic there are 2,588 DDoS flows for every Brute Force flow. A detector can reach 99.5% accuracy and still miss three of every four Brute Force attacks. This project reproduces that blind spot from the base paper, then closes most of it.

Part 1 · Reproduction

The paper's accuracy, and the paper's blind spot

Finding

The paper's Table 6 swaps precision and recall. It lists the 8-class Random Forest at recall 0.910 and precision 0.705, but its own confusion matrix (Table 8) gives recall 0.706 and precision 0.917. Its example notebook calls recall_score(y_pred, y_test), with the arguments in the wrong order.

Part 2 · Improvement

Every rebalancing method beats the baseline

Five ways of handling the imbalance, each applied to the training split only and compared with the baseline trained on the same seed and scored on the same test rows. For the Random Forest, all five raise macro-F1 with a paired bootstrap p below 0.05 on every seed.

Threshold tuning gives the best macro-F1 without touching the training data or the model size. SMOTE catches the most rare-class flows, at a price: Web precision falls from 0.901 to 0.443, so more alerts are false.

Part 2 · Across models

A 1.1 MB decision tree comes close to the 169 MB forest

An IoT gateway has little memory to spare. With class weights, a single Decision Tree reaches macro-F1 0.841 in 1.1 MB and labels a flow in 0.11 µs. LightGBM is unstable without rebalancing (0.503 ± 0.126 across seeds) and becomes reliable with it.

Part 2 · 34 attack types

Four attack types the baseline never catches

At the finest level the baseline Random Forest labels none of the test flows of four attack types correctly. SMOTE finds some of each and lifts macro-F1 from 0.751 to 0.807, with rare-class recall from 0.526 to 0.650.

Part 3 · Extension

20 features do the work of 46

Features ranked by mutual information on the training split, then the tuned Random Forest retrained on the top k. At 20 features macro-F1 is 0.856 (0.851 with all 46), prediction takes 3.1 instead of 4.0 µs per flow and the model shrinks from 169 to 121 MB. Inter-arrival time (IAT) ranks first under mutual information, forest importance and RFE alike.

    Data hygiene

    One test flow in six was already in the training data

    CICIoT2023 contains many exact duplicate rows. Split without removing them, 15.9% of test flows (44,441) have an identical copy in the training split, so part of the test measures memory rather than detection. Every result on this page uses the de-duplicated split.

    How the numbers were made

    One frozen split, three seeds, paired tests

    Runs
    123 training runs in 2.7 hours on a Kaggle CPU
    Split
    Test 20%, then validation 10% of the rest, stratified on all 34 classes and never resampled
    Rebalancing
    Training split only; SMOTE raises each rare class to 50,000 rows
    Thresholds
    Per-class decision weights tuned on the validation split
    Significance
    Paired bootstrap (1,000 resamples) and McNemar test against the same-seed baseline
    Models
    Decision Tree, Random Forest (100 trees), LightGBM (100 rounds), Balanced Random Forest
